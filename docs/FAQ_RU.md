# Часто задаваемые вопросы (FAQ)

## Общие вопросы

### Что такое MusicVerse Pro?
MusicVerse Pro — это Telegram Mini App с интеграцией бота, который предоставляет поиск музыки, управление плейлистами и персонализированные рекомендации через внешние API провайдеры.

### Это бесплатно?
Да, MusicVerse Pro — это open source проект и бесплатен для использования. Однако вам нужно настроить собственные API ключи для музыкальных провайдеров.

### Какие музыкальные провайдеры поддерживаются?
В настоящее время поддерживается интеграция с:
- Spotify API
- Deezer API
- Apple Music API
- Last.fm API

Вы можете добавить дополнительных провайдеров, реализовав интерфейс музыкального сервиса.

## Вопросы по настройке

### Как получить Telegram Bot Token?
1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Сохраните токен, предоставленный BotFather

### Нужен ли HTTPS для Mini App?
Да, Telegram требует HTTPS для Mini Apps. Вы можете использовать:
- Let's Encrypt для бесплатных SSL сертификатов
- Облачные платформы (Heroku, Vercel) предоставляют HTTPS по умолчанию
- Cloudflare для бесплатного SSL

### Как получить ключи музыкальных API?
У каждого провайдера разные требования:
- **Spotify**: Создайте приложение на [Spotify Developer Dashboard](https://developer.spotify.com/)
- **Deezer**: Зарегистрируйтесь на [Deezer Developers](https://developers.deezer.com/)
- **Apple Music**: Зарегистрируйтесь на [Apple Developer](https://developer.apple.com/)

## Технические вопросы

### Какие технологии используются?
- **Backend**: Node.js с Express.js
- **Frontend**: HTML, CSS, JavaScript
- **База данных**: PostgreSQL
- **Кэш**: Redis
- **Бот**: Telegram Bot API

### Могу ли я использовать Python вместо Node.js?
Да! Архитектура поддерживает как Node.js, так и Python. Зависимости Python находятся в `requirements.txt`.

### Как переключаться между музыкальными провайдерами?
Настройте провайдера в вашем файле `.env` или реализуйте функцию выбора провайдера в настройках.

### Могу ли я запустить это без Docker?
Да, вы можете запустить напрямую с Node.js:
```bash
npm install
npm start
```

## Вопросы по развертыванию

### Каковы требования к хостингу?
- Node.js 16+ или Python 3.8+
- База данных PostgreSQL
- Redis (опционально, для кэширования)
- Домен с HTTPS
- Минимум 512MB RAM

### Какие платформы хостинга рекомендуются?
- **VPS**: DigitalOcean, Linode, AWS EC2
- **PaaS**: Heroku, Railway, Render
- **Serverless**: Vercel (для Mini App), AWS Lambda

### Как развернуть на Heroku?
```bash
heroku create ваше-имя-приложения
heroku config:set TELEGRAM_BOT_TOKEN=ваш_токен
git push heroku main
```

См. [Руководство по развертыванию](DEPLOYMENT_RU.md) для подробных инструкций.

## Вопросы по использованию

### Как пользователи получают доступ к Mini App?
Пользователи могут получить доступ:
1. Запустив вашего бота: `/start`
2. Нажав кнопку "Открыть Mini App"
3. Или используя кнопку меню, если настроена

### Могут ли пользователи использовать бота без открытия Mini App?
Да! Бот предоставляет полную функциональность через команды:
- `/music` - Получить рекомендации
- `/search` - Поиск музыки
- `/favorites` - Просмотр избранного

### Как добавить пользовательские команды?
1. Добавьте обработчик в `bot/handlers.js`
2. Зарегистрируйте команду в `bot/index.js`
3. Обновите команды бота в BotFather

## Устранение неполадок

### Бот не отвечает на команды
- Проверьте правильность токена бота
- Убедитесь, что бот запущен: `pm2 status`
- Проверьте логи: `pm2 logs`
- Убедитесь в наличии сетевого подключения

### Mini App не загружается
- Проверьте настройку HTTPS
- Проверьте URL Mini App в BotFather
- Проверьте настройки CORS
- Просмотрите консоль браузера на наличие ошибок

### Ошибки подключения к базе данных
- Проверьте правильность DATABASE_URL
- Проверьте, что PostgreSQL запущен
- Протестируйте подключение: `psql $DATABASE_URL`
- Проверьте правила файрвола

### Проблемы с ограничением запросов API
- Реализуйте кэширование с Redis
- Добавьте троттлинг запросов
- Используйте очередь для пакетных операций
- Рассмотрите обновление плана API

## Вопросы безопасности

### Безопасны ли данные пользователей?
Да, приложение:
- Использует аутентификацию Telegram
- Валидирует данные Web App
- Хранит пароли в зашифрованном виде
- Использует HTTPS для всех соединений

### Как обрабатывается аутентификация?
Аутентификация использует верификацию данных Telegram Web App. Токен бота используется для проверки подлинности запросов от Mini App.

### Могу ли я увидеть API ключи в коде?
Нет, все чувствительные данные должны храниться в переменных окружения (файл `.env`) и никогда не коммититься в репозиторий.

## Вопросы производительности

### Сколько пользователей может обработать?
Зависит от хостинга:
- Базовый VPS: Сотни одновременных пользователей
- Масштабированная настройка: Тысячи одновременных пользователей

### Как улучшить производительность?
- Включите кэширование Redis
- Используйте CDN для статических ресурсов
- Оптимизируйте запросы к базе данных
- Реализуйте connection pooling
- Используйте горизонтальное масштабирование

### Что насчет лимитов API?
- Кэшируйте ответы API
- Реализуйте очередь запросов
- Используйте несколько API ключей (если разрешено)
- Мониторьте использование и оптимизируйте
