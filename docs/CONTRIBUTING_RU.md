# Участие в разработке MusicVerse Pro

Спасибо за ваш интерес к участию в MusicVerse Pro! Этот документ предоставляет руководство по внесению вклада в проект.

## Начало работы

1. Форкните репозиторий
2. Клонируйте ваш форк: `git clone https://github.com/ВАШ_USERNAME/musicverse-pro.git`
3. Создайте ветку для функции: `git checkout -b feature/название-вашей-функции`
4. Внесите изменения
5. Закоммитьте изменения: `git commit -m "Add: описание вашей функции"`
6. Запушьте в ваш форк: `git push origin feature/название-вашей-функции`
7. Создайте Pull Request

## Настройка для разработки

1. Установите зависимости:
```bash
npm install
```

2. Скопируйте переменные окружения:
```bash
cp .env.example .env
```

3. Запустите сервер разработки:
```bash
npm run dev
```

## Стиль кода

- Следуйте существующему стилю кода
- Используйте ESLint для JavaScript: `npm run lint`
- Используйте Prettier для форматирования: `npm run format`
- Пишите понятные, описательные сообщения коммитов
- Добавляйте комментарии для сложной логики

## Сообщения коммитов

Следуйте формату conventional commits:

```
Тип: Краткое описание

Более длинное описание при необходимости

Fixes #номер_issue
```

Типы:
- `Add:` - Новая функция
- `Fix:` - Исправление бага
- `Update:` - Обновление существующей функции
- `Refactor:` - Рефакторинг кода
- `Docs:` - Изменения в документации
- `Test:` - Добавление или обновление тестов
- `Style:` - Изменения стиля кода (форматирование и т.д.)

## Процесс Pull Request

1. Обновите README.md с деталями изменений при необходимости
2. Обновите документацию в папке `docs/`
3. Убедитесь, что все тесты проходят
4. Убедитесь, что код следует руководству по стилю
5. Обновите CHANGELOG.md при необходимости
6. Запросите ревью у мейнтейнеров

## Тестирование

- Пишите тесты для новых функций
- Убедитесь, что существующие тесты проходят: `npm test`
- Тестируйте на разных платформах, если возможно
- Тестируйте функциональность как бота, так и Mini App

## Документация

- Обновляйте API документацию для новых endpoints
- Обновляйте спецификацию бота для новых команд
- Добавляйте комментарии к сложному коду
- Обновляйте README.md для значительных изменений

## Сообщение о багах

При сообщении о багах включите:
- Понятное описание проблемы
- Шаги для воспроизведения
- Ожидаемое поведение
- Фактическое поведение
- Скриншоты при необходимости
- Детали окружения (ОС, версия Node и т.д.)

## Запросы функций

При предложении функций:
- Предоставьте понятное описание
- Объясните вариант использования
- Рассмотрите влияние на существующую функциональность
- Будьте открыты к обсуждению

## Ревью кода

Все вклады будут проверены мейнтейнерами. Пожалуйста, будьте терпеливы и отзывчивы к обратной связи.

## Лицензия

Внося вклад, вы соглашаетесь, что ваши вклады будут лицензированы под лицензией ISC.

## Вопросы?

Не стесняйтесь открывать issue для любых вопросов о участии.

Спасибо за вклад в MusicVerse Pro! 🎵
