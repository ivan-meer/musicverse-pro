# Спецификация Telegram бота

## Команды бота

### Базовые команды

#### /start
- **Описание**: Инициализация бота и показ приветственного сообщения
- **Использование**: `/start`
- **Ответ**: Приветственное сообщение с inline-клавиатурой, содержащей:
  - "🚀 Открыть Mini App" (кнопка Web App)
  - "🎵 Найти музыку" (Callback)
  - "⚙️ Настройки" (Callback)
  - "❓ Помощь" (Callback)

#### /help
- **Описание**: Показать справочную информацию и доступные команды
- **Использование**: `/help`
- **Ответ**: Список всех команд и функций

#### /music
- **Описание**: Получить персонализированные музыкальные рекомендации
- **Использование**: `/music`
- **Ответ**: 
  - Сообщение загрузки
  - Список из 5 рекомендованных треков с деталями
  - Кнопка для открытия рекомендаций в Mini App

#### /search [запрос]
- **Описание**: Поиск музыки
- **Использование**: `/search электронная музыка`
- **Ответ**: Результаты поиска с информацией о треках

#### /playlists
- **Описание**: Просмотр плейлистов пользователя
- **Использование**: `/playlists`
- **Ответ**: Список плейлистов с inline-кнопками

#### /favorites
- **Описание**: Просмотр избранных треков
- **Использование**: `/favorites`
- **Ответ**: Список избранных треков

### Расширенные команды

#### /settings
- **Описание**: Настройка параметров бота
- **Использование**: `/settings`
- **Опции**:
  - Выбор языка
  - Настройки уведомлений
  - Выбор API провайдера

#### /stats
- **Описание**: Просмотр статистики прослушивания
- **Использование**: `/stats`
- **Ответ**: Статистика пользователя и инсайты

## Callback запросы

### Callback главного меню
- `open_app` - Открыть Mini App
- `discover` - Показать опции поиска музыки
- `settings` - Открыть меню настроек
- `help` - Показать справочную информацию

### Действия с музыкой
- `play:track_id` - Воспроизвести трек
- `favorite:track_id` - Добавить/удалить из избранного
- `playlist:playlist_id` - Просмотреть плейлист
- `share:track_id` - Поделиться треком

### Пагинация
- `next:page_num` - Следующая страница
- `prev:page_num` - Предыдущая страница

```javascript
    url: 'https://ваш-домен.com'
  }

```

### Получение данных от Web App
Бот получает данные, когда пользователи отправляют информацию из Mini App:

```javascript
bot.on('web_app_data', (msg) => {
  const data = JSON.parse(msg.web_app_data.data);
  // Обработка данных
});
```

**Ожидаемый формат данных:**
```json
{
  "action": "share_favorites",
  "favorites": ["track_id_1", "track_id_2"],
  "timestamp": "2024-01-01T00:00:00Z"
}
```

## Обработка ошибок

### Дружественные сообщения об ошибках
- Ошибки подключения: "⚠️ Проблема с подключением. Попробуйте снова."
- Ошибки API: "❌ Сервис временно недоступен."
- Неверный ввод: "❓ Неверная команда. Используйте /help для помощи."

### Логирование ошибок
Все ошибки должны логироваться с:
- Временной меткой
- ID пользователя
- Командой/действием
- Деталями ошибки

## Ограничение запросов

### Лимиты бота (Telegram)
- 30 сообщений в секунду разным пользователям
- 1 сообщение в секунду одному пользователю

### Реализация
```javascript
const rateLimiter = new Map();

function checkRateLimit(userId) {
  const lastMessage = rateLimiter.get(userId);
  const now = Date.now();
  
  if (lastMessage && now - lastMessage < 1000) {
    return false; // Превышен лимит
  }
  
  rateLimiter.set(userId, now);
  return true;
}
```

## Уведомления

### Уведомления пользователей
- Доступны новые рекомендации
- Обновления плейлистов
- Системные объявления

### Реализация
```javascript
async function sendNotification(userId, message) {
  try {
    await bot.sendMessage(userId, message, {
      parse_mode: 'Markdown',
      disable_notification: false
    });
  } catch (error) {
    console.error('Ошибка уведомления:', error);
  }
}
```
