# Начало работы с MusicVerse Pro

Это руководство поможет вам настроить и запустить MusicVerse Pro на вашем локальном компьютере или сервере.

## Предварительные требования

Перед началом убедитесь, что у вас есть:
- Node.js 16 или выше
- npm или yarn менеджер пакетов
- Аккаунт Telegram
- (Опционально) PostgreSQL и Redis для продакшена

## Шаг 1: Создание Telegram бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Выберите имя для вашего бота (например, "MusicVerse Pro")
4. Выберите username для бота (должен заканчиваться на 'bot', например, "musicverse_pro_bot")
5. Сохраните токен бота, который даст вам BotFather

### Настройка команд бота

Отправьте BotFather:
```
/setcommands
```

Затем выберите вашего бота и вставьте:
```
start - Запустить бота
help - Показать справку
music - Получить рекомендации
search - Поиск музыки
playlists - Ваши плейлисты
favorites - Избранные треки
settings - Настройки
```

## Шаг 2: Клонирование репозитория

```bash
git clone https://github.com/ivan-meer/musicverse-pro.git
cd musicverse-pro
```

## Шаг 3: Установка зависимостей

```bash
npm install
```

## Шаг 4: Настройка переменных окружения

1. Скопируйте файл с примером переменных окружения:
```bash
cp .env.example .env
```

2. Отредактируйте файл `.env` вашими данными:
```env
# Обязательно: Токен вашего бота от BotFather
TELEGRAM_BOT_TOKEN=ваш_токен_бота
TELEGRAM_BOT_USERNAME=username_вашего_бота

# Обязательно: URL вашего Mini App (для разработки используйте localhost)
MINI_APP_URL=http://localhost:3000

# Опционально: Настройки Music API
MUSIC_API_KEY=ваш_ключ_api
MUSIC_API_SECRET=ваш_секрет_api
MUSIC_API_BASE_URL=https://api.music-provider.com

# Опционально: База данных (не требуется для базового тестирования)
DATABASE_URL=postgresql://user:password@localhost:5432/musicverse
REDIS_URL=redis://localhost:6379

# Настройки сервера
PORT=3000
NODE_ENV=development
```

### Важные замечания:
- Для локальной разработки можно использовать `http://localhost:3000` как MINI_APP_URL
- Ключи Music API опциональны для начального тестирования (приложение будет использовать тестовые данные)
- База данных опциональна для базовой функциональности

## Шаг 5: Запуск приложения

### Режим разработки (с автоперезагрузкой):
```bash
npm run dev
```

### Продакшн режим:
```bash
npm start
```

Вы должны увидеть:
```
Server running on port 3000
Bot @ваш_бот_username is running...
```

## Шаг 6: Тестирование бота

1. Откройте Telegram
2. Найдите вашего бота по username
3. Отправьте команду `/start`
4. Вы должны увидеть приветственное сообщение с кнопками

### Доступные команды:
- `/start` - Показать меню приветствия
- `/help` - Показать справочную информацию
- `/music` - Получить музыкальные рекомендации

## Шаг 7: Настройка Mini App (опционально для тестирования)

Для локального тестирования без HTTPS кнопка Mini App не будет работать. Чтобы протестировать Mini App локально:

### Вариант 1: Использование ngrok для HTTPS туннеля
```bash
# Установите ngrok
npm install -g ngrok

# Запустите ваше приложение
npm start

# В другом терминале создайте HTTPS туннель
ngrok http 3000

# Скопируйте HTTPS URL (например, https://abc123.ngrok.io)
# Обновите MINI_APP_URL в .env
# Перезапустите приложение
```

### Вариант 2: Тестирование без Mini App
Вы можете протестировать всю функциональность бота без Mini App:
- Используйте команды бота: `/music`, `/search` и т.д.
- Бот работает полностью без веб-интерфейса

### Вариант 3: Развертывание для получения HTTPS
См. [DEPLOYMENT.md](DEPLOYMENT.md) для вариантов развертывания с HTTPS.

## Шаг 8: Настройка Mini App в BotFather (когда HTTPS доступен)

Когда у вас есть HTTPS URL (от развертывания или ngrok):

1. Отправьте `/newapp` в @BotFather
2. Выберите вашего бота
3. Предоставьте:
   - Название приложения: MusicVerse Pro
   - Описание: Ваш персональный музыкальный компаньон
   - Фото: изображение 640x360px вашего приложения
   - Web App URL: Ваш HTTPS URL
   - Короткое имя: musicverse

4. Обновите `.env` вашим HTTPS URL:
```env
MINI_APP_URL=https://ваш-домен.com
```

5. Перезапустите приложение

## Шаг 9: Тестирование полной системы

1. **Тестирование команд бота:**
   - Отправьте `/start` - Должно показать приветственное сообщение
   - Отправьте `/help` - Должно показать справочную информацию
   - Отправьте `/music` - Должно показать рекомендации

2. **Тестирование Mini App (если HTTPS настроен):**
   - Нажмите кнопку "Открыть Mini App"
   - Должен открыться веб-интерфейс
   - Протестируйте навигацию между вкладками
   - Протестируйте добавление в избранное


## Устранение неполадок

### Бот не отвечает
- Проверьте правильность токена бота в `.env`
- Убедитесь, что приложение запущено: проверьте вывод консоли
- Попробуйте команду `/start` снова

### Ошибка "Polling error" в консоли
- Токен бота может быть неправильным
- Другой экземпляр может работать с тем же токеном
- Проверьте сетевое подключение

### Кнопка Mini App не работает
- Убедитесь, что MINI_APP_URL использует HTTPS (не HTTP)
- Проверьте, что Mini App настроен в BotFather
- Проверьте доступность URL

### Порт уже используется
- Измените PORT в `.env` на другой порт (например, 3001)
- Или остановите процесс, использующий порт 3000:
  ```bash
  # Windows
  netstat -ano | findstr :3000
  taskkill /PID <PID> /F
  ```

## Следующие шаги

Теперь, когда ваш бот работает:

1. **Настройте бота:**
   - Отредактируйте `bot/handlers.js` для изменения ответов команд
   - Добавьте новые команды в `bot/index.js`

2. **Настройте Mini App:**
   - Отредактируйте `miniapp/index.html` для изменения UI
   - Измените `miniapp/css/style.css` для стилизации
   - Обновите `miniapp/js/app.js` для функциональности

3. **Добавьте интеграцию Music API:**
   - Получите API ключи от музыкальных провайдеров (Spotify, Deezer и т.д.)
   - Обновите `bot/services/musicService.js` реальными API вызовами
   - Настройте API credentials в `.env`

4. **Разверните приложение:**
   - См. [DEPLOYMENT.md](DEPLOYMENT.md) для руководств по развертыванию
   - Рассмотрите Heroku, Railway или VPS хостинг

5. **Изучите документацию:**
   - [API Specification](API_SPECIFICATION.md) - API endpoints
   - [Bot Specification](BOT_SPECIFICATION.md) - Функции бота
   - [Architecture](ARCHITECTURE.md) - Дизайн системы
   - [FAQ](FAQ.md) - Частые вопросы
